# Proyecto de prácticas: algoritmos de regresión

## Contenido

- `main.tex`: guía de instrucciones, aclaraciones, protocolo de evaluación, rúbrica y descripción de los 21 métodos.
- `plantillas_ejercicio/`: 21 fuentes `.py` que contienen únicamente pseudocódigo detallado en comentarios.

## Compilar

Abre `main.tex` en LaTeX Workshop, TeXstudio u otro editor LaTeX y compílalo con pdfLaTeX. El proyecto no incluye los CSV simulados ni los entrenadores completos: se encuentran en el proyecto IFCD107 original, indicados en cada plantilla.

## Usar las plantillas

Cada plantilla corresponde a un solo algoritmo. El alumnado debe completar los pasos comentados y mantener la separación entre datos de entrenamiento, validación cruzada y prueba. Los entrenadores funcionales del proyecto original sirven como referencia posterior a la práctica.

Todos los datos de ejemplo son simulados y no describen expedientes reales.
